# JavaNinja

Repositório de estudos em Java, feito durante minha formação em Análise e Desenvolvimento de Sistemas (ADS). Reúne exercícios e desafios praticando lógica de programação e orientação a objetos.

## Estrutura

- `src/Desafio3` — Sistema de gerenciamento de ninjas usando herança, polimorfismo (`@Override`, `instanceof`), coleções (`ArrayList`) e um menu interativo com `Scanner`, incluindo validação de entrada com `try/catch`.
- `src/Condicoes` — Exercícios de estruturas condicionais (`if/else`, `switch`, operadores ternários).
- `src/TiposDeDados` — Exercícios de tipos primitivos e não-primitivos.
- `src/nivelBasico` — Exercícios introdutórios (arrays, laços de repetição).
- `src/nivelIntermediario` — Exercícios de nível intermediário.

## Tecnologias

- Java
- IntelliJ IDEA
- Conceitos: Programação Orientada a Objetos (herança, polimorfismo, encapsulamento), coleções, tratamento de exceções
